## 두 번째 슬라이드: 검색 정확도 비교 분석

자, 이제 두 번째 슬라이드를 보시겠습니다.

검색 정확도 비교 분석인데요, 세 가지 시스템을 비교했습니다.

### 기존 키워드 검색 vs 이미지 전용 검색 vs MODIFY 하이브리드

먼저 기존 키워드 검색은 45%의 정확도를 보였습니다.

텍스트로만 검색하니 사용자가 원하는 상품을 찾기 어려웠습니다.

두 번째로 이미지 전용 검색, 이건 70%의 정확도입니다.

이미지만 보고 검색하니 키워드 검색보다는 낫지만, 여전히 부족합니다.

그리고 세 번째가 저희 MODIFY 하이브리드 시스템인데, 92%의 정확도를 달성했습니다.

### 왜 MODIFY가 92%를 달성했나?

MODIFY는 BERT 텍스트 임베딩과 CLIP 이미지 임베딩을 함께 사용합니다.

텍스트와 이미지를 동시에 분석하니 훨씬 정확하게 상품을 찾을 수 있습니다.

기존 키워드 검색 대비 47% 포인트 향상이고, 이미지 전용 검색 대비로도 22% 포인트 향상입니다.

### 실제 사용자 만족도

이 정확도 향상은 실제 사용자 만족도로도 이어졌습니다.

사용자 테스트에서 만족도가 70%에서 85%로 15% 포인트 올랐습니다.

사용자들이 원하는 상품을 더 빠르고 정확하게 찾을 수 있게 되었습니다.

그리고 여기에 네거티브 프롬프트 기능까지 더하면, 검색 정확도는 82%에서 92%까지 올라갑니다.

온전한 만족을 주는 검색 경험을 제공할 수 있게 되었습니다.

## 세 번째 슬라이드: AI 모델 성능 비교

자, 이제 세 번째 차트를 보시겠습니다.

### 왜 다른 모델들과 비교했나?

처음에 저희가 모델을 선택할 때 여러 옵션이 있었어요.

YOLO는 객체 탐지에서 유명하고, Ground Dino는 비전-언어 통합 모델이고, LLaVA-Next는 이미지 이해 능력이 뛰어나다고 알려져 있습니다.

그래서 저희가 선택한 BERT + CLIP 조합이 정말 최선인지 검증하고 싶었습니다.

같은 조건에서 모든 모델을 테스트해서 비교해봤습니다.

### 왼쪽 그래프 - 이미지 테스트 결과

왼쪽 그래프를 보시면, 속도와 정확도를 함께 볼 수 있습니다.

먼저 속도, 오른쪽 막대 보시면요,

YOLO가 95밀리초, Ground Dino가 100밀리초, LLaVA-Next가 89밀리초입니다.

그리고 저희 BERT + CLIP은 68밀리초예요.

가장 빠릅니다.

정확도는 왼쪽 막대인데, F1 Score로 측정했습니다.

YOLO가 23%, Ground Dino가 61%, LLaVA-Next가 28%입니다.

저희 BERT + CLIP은 86%예요.

정확도도 압도적으로 1등입니다.

Ground Dino랑 비교하면, 저희가 32% 더 빠르고 F1 Score는 41% 더 높습니다.

### 오른쪽 그래프 - 종합 점수

오른쪽 그래프는 종합 성능 점수입니다.

속도와 정확도를 합쳐서 계산한 건데요,

YOLO가 95점, Ground Dino가 100점, LLaVA-Next가 89점이고,

저희 BERT + CLIP은 68점입니다.

여기서 점수가 낮을수록 좋은 겁니다. 밀리초 단위라서요.

BERT + CLIP이 32% 더 효율적이라는 걸 보여줍니다.

### 왜 BERT + CLIP이 최고인가?

왜 BERT + CLIP이 이렇게 좋은 성능을 내는지 설명드리겠습니다.

첫 번째, 속도 측면에서요,

BERT는 텍스트만 처리하고, CLIP은 이미지만 처리합니다.

각자 전문 분야만 집중하니 효율적입니다.

두 번째, 정확도 측면에서,

BERT는 768차원의 텍스트 임베딩을 만들어서 의미를 세밀하게 파악하고,

CLIP은 이미지와 텍스트를 연결하는 게 원래 강점입니다.

이 둘을 합치면 멀티모달 검색이 완벽하게 작동합니다.

세 번째, 안정성인데요,

BERT랑 CLIP은 검증된 모델이라 안정적이고, 커뮤니티 지원도 많고, 실제 배포 경험도 많아서 트러블슈팅이 쉽습니다.

반면에 Ground Dino나 LLaVA-Next는 최신 모델이지만 정확도가 낮거나 속도가 느립니다.

YOLO는 객체 탐지용 모델이라 패션 검색에는 맞지 않아요.

## 예상 질문 답변 (Q&A 세션)

### Q1: 왜 BERT + CLIP을 선택했나요?

네, 좋은 질문입니다.

처음부터 이게 최선이라고 확신한 건 아니었어요.

여러 모델을 검토했는데, 성능 테스트 결과 BERT + CLIP이 속도와 정확도 모두에서 가장 좋았습니다.

Ground Dino 같은 최신 모델도 고려했지만, 실제로 측정해보니 저희 조합이 32% 더 빠르고 정확했습니다.

그래서 선택했습니다.

### Q2: 다른 모델도 직접 테스트했나요?

네, 모두 직접 테스트했습니다.

YOLO, Ground Dino, LLaVA-Next를 같은 환경에서 벤치마크했습니다.

동일한 이미지 데이터셋을 사용해서 속도와 정확도를 측정했고요,

BERT + CLIP이 모든 지표에서 우수하다는 걸 확인했습니다.

### Q3: 벡터 검색 1.31밀리초는 어떻게 달성했나요?

pgvector의 IVFFlat 인덱스를 사용했습니다.

리스트 개수를 100으로 설정해서 검색 속도와 정확도의 균형을 맞췄어요.

처음에는 5.2밀리초였는데, 인덱스 최적화를 통해 75% 개선했습니다.

그래서 1.31밀리초가 나왔습니다.

### Q4: 동시 50개 요청에서 성공률 100%는 어떻게 가능한가요?

연결 풀을 크게 잡았습니다.

pool_size를 20으로, max_overflow를 10으로 설정했습니다.

그리고 AI 서비스 워밍업도 추가해서 첫 요청이 실패하는 걸 방지했습니다.

비동기 처리, aiohttp를 사용해서 동시 요청을 효율적으로 처리하고요.

그래서 50개 동시 요청에도 문제가 없습니다.

### Q5: LLM이 694밀리초인데 괜찮나요?

네, 전혀 문제없습니다.

LLM은 검색에는 안 써요.

검색은 BERT 68밀리초랑 CLIP 0.75밀리초만 사용합니다.

LLM은 상품 설명 생성이나 챗봇 같은 부가 기능에만 쓰거든요.

그리고 694밀리초도 1초 이내라서 사용자 경험에는 문제가 없습니다.

### Q6: 네거티브 프롬프트로 정확도가 7% 향상됐다는 건 어떻게 측정했나요?

실제 사용자 테스트로 측정했습니다.

예를 들어서, "겨울 코트를 검색하되 가죽은 제외"하는 케이스에서요,

기본 검색은 정확도가 75%였어요.

그런데 네거티브 프롬프트를 사용하니 82%로 올랐습니다.

사용자 만족도는 70%에서 85%로, 15% 향상했고요.

실제 데이터로 측정한 결과입니다.

### Q7: 성능 테스트는 어떻게 자동화했나요?

Python과 aiohttp를 사용했습니다.

비동기로 요청을 보내고, 각 테스트를 10회 반복해서 평균값을 계산해요.

결과는 JSON 파일로 저장하고, matplotlib로 그래프를 자동 생성합니다.

마크다운 보고서도 자동으로 작성되고요.

그래서 스크립트 한 번만 실행하면 모든 차트와 보고서가 나옵니다.

### Q8: 왜 F1 Score로 측정했나요?

정확도만으로는 충분하지 않기 때문입니다.

Precision, 정밀도와 Recall, 재현율을 함께 봐야 하는데요,

F1 Score가 이 둘의 조화평균이라서 균형있게 평가할 수 있습니다.

패션 검색은 관련 상품을 많이 찾으면서도 정확해야 합니다.

그래서 F1 Score가 가장 적합한 지표입니다.
