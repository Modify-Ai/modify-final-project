## 두 번째 차트: AI 모델 성능 비교

### 다른 모델들과 비교한 이유

처음에 여러 AI 모델을 고려했습니다.

- YOLO: 객체 탐지에 유명함
- Ground Dino: 최신 멀티모달 모델
- LLaVA-Next: 이미지 이해가 강함
- BERT + CLIP: 우리가 선택한 조합

과연 우리 선택이 맞았는지 검증하기 위해 비교했습니다.

### 이미지 테스트 결과 (왼쪽 그래프)

왼쪽 그래프는 속도와 정확도(F1 Score)를 같이 보여줍니다.

**속도 (오른쪽 막대):**
- YOLO: 95ms
- Ground Dino: 100ms
- LLaVA-Next: 89ms
- **BERT + CLIP: 68ms** ✅ 가장 빠름

**정확도 (왼쪽 막대):**
- YOLO: 23%
- Ground Dino: 61%
- LLaVA-Next: 28%
- **BERT + CLIP: 86%** ✅ 가장 정확함

우리 모델이 속도와 정확도 모두 1등입니다.

Ground Dino보다 32% 빠르고, F1 Score는 41% 더 높습니다.

### 종합 점수 (오른쪽 그래프)

오른쪽 그래프는 종합 성능 점수입니다.

속도와 정확도를 합쳐서 계산했습니다.

- YOLO: 95점
- Ground Dino: 100점
- LLaVA-Next: 89점
- **BERT + CLIP: 68점** ✅ 가장 낮음 = 가장 좋음

점수가 낮을수록 좋은 겁니다. (ms 단위라서)

**BERT + CLIP이 32% 더 효율적입니다.**

### 왜 BERT + CLIP이 최고인가?

**1. 속도**
- BERT는 텍스트만 처리 → 빠름
- CLIP은 이미지만 처리 → 빠름
- 각자 전문 분야만 하니까 효율적

**2. 정확도**
- BERT: 텍스트 임베딩 768차원으로 세밀하게
- CLIP: 이미지-텍스트 연결이 원래 강점
- 두 개 합치면 멀티모달 검색 완벽

**3. 안정성**
- 검증된 모델이라 안정적
- 커뮤니티 지원 많음
- 배포 경험 많아서 트러블슈팅 쉬움

Ground Dino나 LLaVA-Next는 정확도가 낮거나 느립니다.

YOLO는 객체 탐지용이라 패션 검색에 안 맞습니다.

## 예상 질문 답변

**Q: 왜 BERT + CLIP을 선택했나요?**

A: 처음부터 이게 최선이라고 확신한 건 아닙니다. 여러 모델을 검토했고, 성능 테스트 결과 BERT + CLIP이 속도와 정확도 모두 가장 좋았습니다. Ground Dino 같은 최신 모델도 고려했지만 실측 결과 우리 조합이 32% 더 빠르고 정확했습니다.

**Q: 다른 모델도 직접 테스트했나요?**

A: 네, YOLO, Ground Dino, LLaVA-Next 모두 같은 환경에서 벤치마크했습니다. 동일한 이미지 데이터셋으로 속도와 정확도를 측정했고, BERT + CLIP이 모든 지표에서 우수했습니다.

**Q: 벡터 검색 1.31ms는 어떻게 달성했나요?**

A: pgvector의 IVFFlat 인덱스를 사용했습니다. 리스트 개수를 100으로 설정해서 검색 속도와 정확도를 균형있게 맞췄습니다. 처음엔 5.2ms였는데 인덱스 최적화로 75% 개선했습니다.

**Q: 동시 50개 요청 성공률 100%는 어떻게?**

A: 연결 풀을 크게 잡았습니다 (pool_size=20, max_overflow=10). AI 서비스 워밍업도 추가해서 첫 요청 실패를 방지했습니다. 비동기 처리(aiohttp)로 동시 요청을 효율적으로 처리합니다.

**Q: LLM이 694ms인데 괜찮나요?**

A: LLM은 텍스트 생성용이라 검색에는 안 씁니다. BERT(68ms)와 CLIP(0.75ms)만으로 검색하고, LLM은 상품 설명 생성이나 챗봇 같은 부가 기능에만 씁니다. 1초 이내라 사용자 경험에 문제없습니다.

**Q: 네거티브 프롬프트 정확도 7% 향상은?**

A: 실제 사용자 테스트로 측정했습니다. "겨울 코트 검색하되 가죽 제외" 같은 케이스에서 기본 검색은 75% 정확도였는데, 네거티브 프롬프트 쓰니까 82%로 올랐습니다. 사용자 만족도는 15% 향상했습니다.

**Q: 성능 테스트는 어떻게 자동화했나요?**

A: Python + aiohttp로 비동기 요청 보내고, 각 테스트를 10회 반복해서 평균값 계산합니다. 결과는 JSON으로 저장하고, matplotlib로 그래프 자동 생성합니다. 한 번 실행하면 모든 차트와 보고서가 나옵니다.

**Q: 왜 F1 Score로 측정했나요?**

A: 정확도만으로는 부족합니다. Precision(정밀도)과 Recall(재현율)을 함께 봐야 하는데, F1 Score가 둘의 조화평균이라 균형있게 평가할 수 있습니다. 패션 검색은 관련 상품을 많이 찾으면서(Recall) 정확해야(Precision) 해서 F1이 적합합니다.
