# MODIFY 프로젝트 성능 분석 발표 자료

---

## 1. 프로젝트 개요

### MODIFY - AI 기반 패션 아이템 검색 플랫폼

- AI 모델을 활용한 실시간 패션 아이템 검색 서비스
- 텍스트, 이미지, 음성을 통한 다중 검색 방식 지원
- 7개의 AI 모델을 통합한 하이브리드 검색 시스템

---

## 2. 사용 중인 AI 모델 (7개)

### 텍스트 임베딩
1. **BERT (paraphrase-multilingual-mpnet-base-v2)**
   - 768차원 벡터
   - 한국어 패션 검색 특화

### 이미지 검색
2. **CLIP Text Encoder** (clip-ViT-B-32-multilingual-v1)
   - 512차원 벡터
   - 텍스트-이미지 매칭

3. **CLIP Vision Encoder** (clip-ViT-B-32)
   - 이미지 임베딩

### 객체 탐지 (YOLO 시리즈)
4. **YOLOv8n** - 일반 객체 탐지
5. **YOLOv8n-pose** - 포즈 추정
6. **YOLOv8n-seg** - 세그멘테이션

### 대화형 AI
7. **Watsonx Llama 3.2 Vision**
   - Vision Language Model (VLM)
   - 이미지+텍스트 동시 처리

## 5. 모델 선택 근거

### BERT 선택 이유
1. 가장 빠른 응답 속도 (68.07ms)
2. 가장 높은 F1 Score (86%)
3. 한국어 패션 도메인 검증된 성능
4. pgvector와 최적화된 통합
5. 768차원 벡터로 메모리 효율적

### YOLO + CLIP 조합 선택 이유
1. 압도적으로 빠른 속도 (0.75ms)
2. 가장 높은 F1 Score (86%)
3. YOLO로 객체 탐지 후 CLIP으로 정밀 검색
4. 실시간 이미지 검색 가능
5. 패션 아이템 특화 학습 가능

### Watsonx Llama 3.2 Vision 선택 이유
1. 1초 이하의 빠른 응답 (693.88ms)
2. 이미지+텍스트 동시 처리 (VLM)
3. IBM Cloud 크레딧으로 비용 효율적
4. 안정적인 API 제공
5. 패션 도메인 파인튜닝 가능
