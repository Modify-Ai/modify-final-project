## 1. 프로젝트 개요

### MODIFY - AI 기반 패션 아이템 검색 플랫폼

**프로젝트 목표**
- AI를 활용한 실시간 패션 아이템 검색 서비스 구축
- 텍스트, 이미지, 음성을 통한 멀티모달 검색 지원
- 관리자 페이지를 통한 효율적인 상품 관리

**기술 스택**
- Backend: FastAPI (Python)
- Frontend: React + TypeScript
- Database: PostgreSQL + pgvector
- AI/ML: 7개 AI 모델 통합
- Infrastructure: Docker + Docker Compose

## 4. 관리자 페이지 개선

- 검색 기능이 작동하지 않음

1. **검색 로직 수정**

3. **데이터베이스 쿼리 최적화**
   - ORDER BY 절 수정
   - 인덱스 활용 개선
   - 쿼리 성능 향상 (10.37ms → 9.98ms)

#### 결과
- 검색 기능 100% 정상 작동

- 사용자 편의성 대폭 개선

## 6. AI 모델 통합 및 최적화

### 7개 AI 모델 통합

#### 1) 텍스트 임베딩

#### 2) 이미지 검색
**CLIP Text Encoder** (clip-ViT-B-32-multilingual-v1)

- 텍스트-이미지 매칭

**CLIP Vision Encoder** (clip-ViT-B-32)
- 이미지 임베딩
- 응답 시간: 0.75ms

**YOLOv8n** - 일반 객체 탐지

- 경량 모델로 빠른 속도

**YOLOv8n-seg** - 세그멘테이션

#### 4) 대화형 AI
**Watsonx Llama 3.2 Vision**
- Vision Language Model (VLM)
- 이미지+텍스트 동시 처리

## 12. 문제 해결 사례

### Case 1: 마이그레이션 순환 참조 오류

**문제**
```
ERROR: Cycle is detected in revisions
(0571cd6f8f9f, 125f6d16a1de, 181bf85da2ce,
6548ddd476c8, 6bb99ad9237c, a1b2c3d4e5f6)
```

**원인 분석**
- `6bb99ad9237c` 리비전이 잘못된 down_revision 참조
- 마이그레이션 체인에 순환 구조 발생

**해결 방법**
```python
# 수정 전
down_revision: Union[str, None] = 'a1b2c3d4e5f6'

# 수정 후
down_revision: Union[str, None] = 'eb7ce1bf9db5'
```

**결과**
- 마이그레이션 정상 실행
- 팀원들과 데이터베이스 동기화 성공

---

### Case 2: AI 서비스 연결 실패

**문제**
- 성능 테스트 시 AI 모델 테스트 실패
- "Server disconnected" 오류 반복

**원인 분석**
- AI 서비스 모델 로딩 시간 미고려
- aiohttp 연결 풀 제한
- 타임아웃 설정 부족

**해결 방법**
1. **워밍업 단계 추가**
```python
async def warmup_ai_service(self, session):
    # AI 서비스가 완전히 시작될 때까지 대기
    async with session.post(
        f"{AI_SERVICE_URL}/api/v1/process-internal",
        json={"query": "test"},
        timeout=aiohttp.ClientTimeout(total=60)
    ) as response:
        if response.status == 200:
            print("AI 서비스 준비 완료")
```

2. **연결 풀 크기 증가**
```python
connector = aiohttp.TCPConnector(limit=100, limit_per_host=30)
```

**결과**
- AI 모델 테스트 100% 성공
- 안정적인 성능 측정 가능
